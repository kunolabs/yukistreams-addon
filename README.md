# Yukistreams

A Stremio addon for anime, Asian drama, movies, and series, with optional debrid support.

> **Project status:** Yukistreams is closed source. I use this repo for public notes, release updates, and issue reports. Bugs and feature requests are welcome under [Issues](../../issues).

## Install

1. Open **<https://stremio.yukistreams.xyz/configure>**.
2. Choose a preset and optional services.
3. Click **Install in Stremio**.

You can also install through Stremio's Community Addons page by searching for Yukistreams.

## Latest update

**v1.0.5 hotfix.1** refreshes the configure page, improves setup controls, and makes Real-Debrid results avoid a few patterns that recently caused playback trouble.

Existing installs can keep working. Reconfigure only if you want to review the new setup flow, add TorBox, or refresh older source choices.

## What you get

- Anime and Asian drama focused catalogs.
- Movies and series support alongside the main Asian-content focus.
- Optional Real-Debrid and TorBox-backed results.
- Some zero-key playback rows where a supported source can be played directly.
- Quality, language, catalog, and result display preferences.
- Encrypted install profiles, so saved keys are not shown back after setup.

## Don't have a debrid account?

Yukistreams can still show catalogs and some direct playback rows without a debrid key, but a supported debrid account is recommended for the fuller and more reliable experience.

## Privacy and safety

- Yukistreams does **not** host or store video files.
- Bring your own Real-Debrid or TorBox account if you want debrid-backed results.
- Your saved keys are encrypted into your install URL and are not shown back after setup.
- Never share your install URL. Anyone with it may be able to use the settings saved inside it.

## What's reportable

Please use [Issues](../../issues) for:

- Broken catalogs or missing rows.
- Playback failures for specific titles.
- Configure-page bugs.
- Reasonable source, preset, language, or catalog requests.

Please report Real-Debrid, TorBox, Stremio app, or third-party service account issues to those services directly.
